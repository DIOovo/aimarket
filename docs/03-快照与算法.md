## ledger.json

- `checked_at`、`timezone`（Asia/Shanghai）、`previous_checked_at`

## 撞车算法（core_key）

实现在 `scripts/finalize.py`：`ALIASES`、`SUFFIXES`、`strip_suffixes()`、`core_key()`、`slugify_words()`、`pretty_name()`、`NAME_OVERRIDE`。2026-11-22 实际写盘脚本 `scripts/finalize_today.py` 会 `import` 这份 `finalize.py`，并在开头对 `fin.ALIASES` 再做增量更新。注意：`scripts/finalize.py` 文件头里仍留着旧的 `OUTDIR=.../competitor-scan-2026-11-21` 和更早的 `PREV_CHECKED_AT`；以 `finalize_today.py` 当天的路径为准，不要直接跑未改路径的旧 `finalize.py` 去覆盖 store。

计算步骤：

1. 取模板 `id_or_slug` 的最后一段，小写，只保留 `[a-z0-9-]`。
2. 用 `strip_suffixes()` 反复去掉站点风格后缀，包括：`ai-video-generator`、`ai-character-swap`、`video-generator`、`ai-video`、`ai-trend`、`ai-dance`、`ai-meme`、`ai-filter`、`yapay-zeka`、`trend`、`ai`。也可以去掉开头的 `ai-`。脚本注释写明：**不要**去掉光秃的 `dance` / `video` / `meme` 这类词，否则会把不同玩法（例如 christmas-dance 与 christmas-ai-video）折在一起。
3. 也用标题做一次同样的后缀剥离，作为备选。
4. 先对 slug core、再对 title core 查 `ALIASES`（例如 `grandpa-handles-dinner` → `fish-cutting`，`gta-ai-filter` → `gta-6-loading-screen`，`boom-clap` → `boom-clap-confetti`）。
5. 若 core 以 `hey-boo-` 开头，去掉此外缀后再查 alias。
6. 相同 `core_key` 出现在 ≥2 家，即算撞车。日报分两块：今日新增之间互相撞车，以及今日新增与他站**存量**撞车。
7. 展示名可用 `NAME_OVERRIDE`，或从标题去掉 “AI Video Generator / AI Trend / AI …” 后缀。

完整 alias 表以脚本为准，不要只靠文档复述。每日结果在 `daily-scans/YYYY-MM-DD/overlaps-today.json`。中文列表通常在日报文末「多家共有」，以及 2026-11-12 至 2026-11-21 的 `多家共有-不含Smew-YYYY-MM-DD.md`（2026-11-22 没有单独出这份，撞车写在日报文末）。把 Smew 从主计数里拆出去，是为了避免 Smew 目录扩容把「有几家在做同一玩法」刷得虚高。

2026-11-22 的 `daily-scans/2026-11-22/run-summary.json`：`overlap_count=12`（当日互相撞车 5 组 + 与存量撞车 7 组）。
